# Admin UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move all bot content (promotions, services + price images, branches, doctor schedules, region menu) into `data/*.json`, generate the LINE reply table from that JSON, and add a password-protected admin API plus a React admin UI to edit it without restarting the server.

**Architecture:** A `services/dataStore.js` module owns reading/writing the JSON files (atomic write, backups, in-memory cache, change listeners). `services/messageTable.js` builds `Map<trigger, Message[]>` from the store using the existing Flex builders in `flexmessage/`; it rebuilds whenever the store changes. `routes/adminRoute.js` exposes login + GET/PUT per resource, guarded by `middlewares/adminAuth.js`. `admin/` is a separate Vite + React app built to `admin/dist` and served by Express at `/admin`.

**Tech Stack:** Node 20 (built-in `node --test`, `crypto`, `fetch`), Express 4, `@line/bot-sdk` 9, Vite 5 + React 18 + react-router-dom 6 (HashRouter).

**Spec:** `docs/superpowers/specs/2026-09-09-admin-ui-design.md`

## Global Constraints

- Node `v20.11.0`, npm `10.2.4`. Windows host (Git Bash available). Do not rely on shell globs inside npm scripts (cmd.exe does not expand them).
- Server side: **no new npm dependencies**. Tests use `node --test` only.
- Data files: `data/promotions.json`, `data/services.json`, `data/branches.json`, `data/regions.json` — UTF-8, 2-space indent, trailing newline.
- Every trigger string is an **exact byte match** of what the LINE Rich Menu sends. Never "normalize" them.
- Follow-up text constant: `"👨‍⚕️ปรึกษาหมอได้เลย หมอตอบเองครับ"`. Schedule trigger prefix: `"สอบถามตารางแพทย์ สาขา"`. Branch map altText: `"สาขา" + trigger`.
- LINE limits: max 12 bubbles per carousel; max 5 messages per reply.
- Admin token TTL 12 hours. Login failure delay 1000 ms (configurable for tests). No `ADMIN_PASSWORD` → every admin endpoint returns 503.
- Admin UI copy is Thai. Vite `base` is `/admin/`. Router is `HashRouter` (so Express needs no SPA fallback).
- Validation error shape: `{ path: "[3].doctors[1].imageUrl", message: "..." }` — `path` is relative to the root array of the resource.
- `README.md` is UTF-16LE encoded; convert to UTF-8 when editing (Task 15).
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

```js
// อ่าน/เขียนไฟล์ข้อมูล data/*.json ที่บอทและหน้า admin ใช้ร่วมกัน
// - cache ในหน่วยความจำ อ่านไฟล์ครั้งแรกครั้งเดียว
// - เขียนแบบ atomic (เขียน .tmp แล้ว rename) และสำรองไฟล์เดิมไว้ใน data/backup/
// - แจ้ง listener ทุกครั้งที่บันทึก เพื่อให้ messageTable สร้างตารางใหม่
const fs = require("fs");
const path = require("path");

const DATA_NAMES = ["promotions", "services", "branches", "regions"];
const MAX_BACKUPS = 20;

function createDataStore(baseDir) {
  const cache = new Map();
  const listeners = [];
  let backupCounter = 0;

  function filePath(name) {
    if (!DATA_NAMES.includes(name)) {
      throw new Error(`unknown data name: ${name}`);
    }
    return path.join(baseDir, `${name}.json`);
  }

  function get(name) {
    const file = filePath(name);
    if (!cache.has(name)) {
      cache.set(name, JSON.parse(fs.readFileSync(file, "utf8")));
    }
    return cache.get(name);
  }

  function backup(name) {
    const source = filePath(name);
    if (!fs.existsSync(source)) return;
    const dir = path.join(baseDir, "backup");
    fs.mkdirSync(dir, { recursive: true });
    const stamp = new Date().toISOString().replace(/[:.]/g, "-");
    const counter = String(backupCounter++).padStart(4, "0");
    fs.copyFileSync(source, path.join(dir, `${name}.${stamp}-${counter}.json`));

    const existing = fs
      .readdirSync(dir)
      .filter((f) => f.startsWith(`${name}.`) && f.endsWith(".json"))
      .sort();
    while (existing.length > MAX_BACKUPS) {
      fs.unlinkSync(path.join(dir, existing.shift()));
    }
  }

  function set(name, value) {
    const target = filePath(name);
    backup(name);
    const tmp = `${target}.tmp`;
    fs.writeFileSync(tmp, JSON.stringify(value, null, 2) + "\n", "utf8");
    fs.renameSync(tmp, target);
    cache.set(name, value);
    listeners.forEach((fn) => fn(name, value));
  }

  function getAll() {
    return Object.fromEntries(DATA_NAMES.map((name) => [name, get(name)]));
  }

  function onChange(fn) {
    listeners.push(fn);
  }

  return { get, set, getAll, onChange, names: DATA_NAMES };
}

let defaultStore = null;
function getDefaultStore() {
  if (!defaultStore) {
    defaultStore = createDataStore(path.join(__dirname, "..", "data"));
  }
  return defaultStore;
}

module.exports = { createDataStore, getDefaultStore, DATA_NAMES };
```

```js
// ตรวจข้อมูลก่อนบันทึก คืน [] ถ้าผ่าน หรือ [{ path, message }] (path เทียบกับ array ราก เช่น "[3].doctors[1].imageUrl")
const DAYS = ["วันจันทร์", "วันอังคาร", "วันพุธ", "วันพฤหัสบดี", "วันศุกร์", "วันเสาร์", "วันอาทิตย์"];
const MENUS = ["main", "thonglor", "both"];
const MAX_PRICE_IMAGES = 12;

const isNonEmpty = (v) => typeof v === "string" && v.trim() !== "";
const isUrl = (v) => typeof v === "string" && /^https?:\/\//.test(v);

function checkArrayRoot(errors, value) {
  if (!Array.isArray(value)) {
    errors.push({ path: "", message: "ต้องเป็นรายการ (array)" });
    return false;
  }
  return true;
}
function checkString(errors, path, v) {
  if (!isNonEmpty(v)) errors.push({ path, message: "ต้องระบุ" });
}
function checkUrl(errors, path, v) {
  if (!isUrl(v)) errors.push({ path, message: "ต้องเป็น URL ขึ้นต้นด้วย http:// หรือ https://" });
}
function checkBool(errors, path, v) {
  if (typeof v !== "boolean") errors.push({ path, message: "ต้องเป็น true/false" });
}
function checkId(errors, path, v) {
  if (!/^[a-z0-9-]+$/.test(String(v ?? ""))) errors.push({ path, message: "id ใช้ได้เฉพาะ a-z, 0-9 และ -" });
}
function checkUnique(errors, items, field, label) {
  const seen = new Map();
  items.forEach((item, i) => {
    const v = item && item[field];
    if (!isNonEmpty(String(v ?? ""))) return;
    if (seen.has(v)) errors.push({ path: `[${i}].${field}`, message: `${label} ซ้ำกับรายการที่ ${seen.get(v) + 1}` });
    else seen.set(v, i);
  });
}
function checkStringList(errors, path, list, check) {
  if (!Array.isArray(list)) {
    errors.push({ path, message: "ต้องเป็นรายการ" });
    return;
  }
  list.forEach((v, i) => check(errors, `${path}[${i}]`, v));
}
function isObject(v) {
  return v !== null && typeof v === "object" && !Array.isArray(v);
}

function validatePromotions(list) {
  const errors = [];
  if (!checkArrayRoot(errors, list)) return errors;
  list.forEach((p, i) => {
    if (!isObject(p)) { errors.push({ path: `[${i}]`, message: "รูปแบบไม่ถูกต้อง" }); return; }
    checkId(errors, `[${i}].id`, p.id);
    checkUrl(errors, `[${i}].image`, p.image);
    checkString(errors, `[${i}].title`, p.title);
    checkStringList(errors, `[${i}].lines`, p.lines, checkString);
    checkString(errors, `[${i}].inquiryText`, p.inquiryText);
    checkBool(errors, `[${i}].hot`, p.hot);
  });
  checkUnique(errors, list, "id", "id");
  return errors;
}

function validateServices(list) {
  const errors = [];
  if (!checkArrayRoot(errors, list)) return errors;
  list.forEach((s, i) => {
    if (!isObject(s)) { errors.push({ path: `[${i}]`, message: "รูปแบบไม่ถูกต้อง" }); return; }
    checkId(errors, `[${i}].id`, s.id);
    checkUrl(errors, `[${i}].image`, s.image);
    checkString(errors, `[${i}].title`, s.title);
    checkString(errors, `[${i}].subtitle`, s.subtitle);
    checkString(errors, `[${i}].actionText`, s.actionText);
    checkBool(errors, `[${i}].hot`, s.hot);
    if (Array.isArray(s.priceImages) && s.priceImages.length > MAX_PRICE_IMAGES) {
      errors.push({ path: `[${i}].priceImages`, message: `รูปราคาได้ไม่เกิน ${MAX_PRICE_IMAGES} รูป` });
    } else {
      checkStringList(errors, `[${i}].priceImages`, s.priceImages, checkUrl);
    }
  });
  checkUnique(errors, list, "id", "id");
  checkUnique(errors, list, "actionText", "ข้อความปุ่ม (actionText)");
  return errors;
}

function sectionNames(regions) {
  if (!Array.isArray(regions)) return [];
  return regions.flatMap((r) => (r && Array.isArray(r.sections) ? r.sections : []));
}

function validateBranches(list, regions) {
  const errors = [];
  if (!checkArrayRoot(errors, list)) return errors;
  const sections = new Set(sectionNames(regions));
  list.forEach((b, i) => {
    if (!isObject(b)) { errors.push({ path: `[${i}]`, message: "รูปแบบไม่ถูกต้อง" }); return; }
    checkId(errors, `[${i}].id`, b.id);
    checkString(errors, `[${i}].trigger`, b.trigger);
    checkString(errors, `[${i}].displayName`, b.displayName);
    if (!sections.has(b.region)) errors.push({ path: `[${i}].region`, message: "ไม่มีภูมิภาคนี้ในรายการภูมิภาค" });
    if (!MENUS.includes(b.menu)) errors.push({ path: `[${i}].menu`, message: `ต้องเป็นหนึ่งใน ${MENUS.join(", ")}` });
    checkBool(errors, `[${i}].enabled`, b.enabled);
    checkString(errors, `[${i}].fontSize`, b.fontSize);
    checkUrl(errors, `[${i}].mapUrl`, b.mapUrl);
    checkUrl(errors, `[${i}].imageUrl`, b.imageUrl);
    checkString(errors, `[${i}].phoneNumber`, b.phoneNumber);
    checkString(errors, `[${i}].lineId`, b.lineId);
    if (b.lineUrl !== undefined && b.lineUrl !== "" && !isUrl(b.lineUrl)) {
      errors.push({ path: `[${i}].lineUrl`, message: "ต้องเป็น URL ขึ้นต้นด้วย http:// หรือ https://" });
    }
    if (b.mainMenuActionText !== undefined && typeof b.mainMenuActionText !== "string") {
      errors.push({ path: `[${i}].mainMenuActionText`, message: "ต้องเป็นข้อความ" });
    }
    if (!Array.isArray(b.doctors)) {
      errors.push({ path: `[${i}].doctors`, message: "ต้องเป็นรายการ" });
    } else {
      b.doctors.forEach((d, j) => {
        const p = `[${i}].doctors[${j}]`;
        if (!isObject(d)) { errors.push({ path: p, message: "รูปแบบไม่ถูกต้อง" }); return; }
        if (!DAYS.includes(d.day)) errors.push({ path: `${p}.day`, message: "ต้องเลือกวันในสัปดาห์" });
        checkString(errors, `${p}.name`, d.name);
        checkString(errors, `${p}.license`, d.license);
        checkUrl(errors, `${p}.imageUrl`, d.imageUrl);
      });
    }
  });
  checkUnique(errors, list, "id", "id");
  checkUnique(errors, list, "trigger", "ข้อความ trigger");
  return errors;
}

function validateRegions(regions, branches) {
  const errors = [];
  if (!checkArrayRoot(errors, regions)) return errors;
  const seen = new Map();
  regions.forEach((r, i) => {
    if (!isObject(r) || !Array.isArray(r.sections)) {
      errors.push({ path: `[${i}].sections`, message: "ต้องเป็นรายการหัวข้อ" });
      return;
    }
    if (r.sections.length === 0) {
      errors.push({ path: `[${i}].sections`, message: "ต้องมีอย่างน้อย 1 หัวข้อ" });
    }
    r.sections.forEach((s, j) => {
      const p = `[${i}].sections[${j}]`;
      if (!isNonEmpty(s)) { errors.push({ path: p, message: "ต้องระบุ" }); return; }
      if (seen.has(s)) errors.push({ path: p, message: "ชื่อหัวข้อซ้ำ" });
      else seen.set(s, p);
    });
  });
  const names = new Set(seen.keys());
  (Array.isArray(branches) ? branches : []).forEach((b) => {
    if (b && !names.has(b.region)) {
      errors.push({ path: "", message: `หัวข้อ "${b.region}" ลบไม่ได้ เพราะสาขา "${b.trigger}" ยังใช้อยู่` });
    }
  });
  return errors;
}

module.exports = {
  validatePromotions, validateServices, validateBranches, validateRegions,
  sectionNames, DAYS, MENUS, MAX_PRICE_IMAGES,
};
```

```js
function buildMainMenuGroups(regions, branches) {

      .filter((b) => inMainMenu(b) && b.region === section)

  if (![promotions, services, branches, regions].every(Array.isArray)) {
    throw new Error("messageTable: ข้อมูลไม่ครบหรือไม่ใช่ array");

      table.set(service.actionText, [
        createFlexMessage(service.actionText, FlexMessageServicePrices({ imagePriceUrl: service.priceImages })),
        followUp,
      ]);

    }
  }
  store.onChange(rebuild);
  return { getTable: () => table, rebuild };
}
```

```js
// ป้องกัน /api/admin ด้วยรหัสผ่านเดียวจาก .env (ADMIN_PASSWORD) และ token HMAC อายุ 12 ชม.
const crypto = require("crypto");

const TOKEN_TTL_MS = 12 * 60 * 60 * 1000;

function isAdminEnabled() {
  return Boolean(process.env.ADMIN_PASSWORD);
}

// ใช้ ADMIN_TOKEN_SECRET ถ้ามี ไม่งั้น derive จาก password (เปลี่ยน password = token เก่าหมดอายุทันที)
function tokenSecret() {
  return process.env.ADMIN_TOKEN_SECRET
    || crypto.createHash("sha256").update(process.env.ADMIN_PASSWORD || "").digest("hex");
}

function sha256(value) {
  return crypto.createHash("sha256").update(String(value ?? "")).digest();
}

function passwordMatches(input) {
  if (!isAdminEnabled()) return false;
  return crypto.timingSafeEqual(sha256(input), sha256(process.env.ADMIN_PASSWORD));
}

function sign(exp) {
  return crypto.createHmac("sha256", tokenSecret()).update(String(exp)).digest("hex");
}

function createToken(now = Date.now()) {
  const expiresAt = now + TOKEN_TTL_MS;
  const token = `${Buffer.from(String(expiresAt)).toString("base64url")}.${sign(expiresAt)}`;
  return { token, expiresAt };
}

function verifyToken(token, now = Date.now()) {
  if (typeof token !== "string") return false;
  const [expPart, signature] = token.split(".");
  if (!expPart || !signature) return false;
  const expiresAt = Number(Buffer.from(expPart, "base64url").toString());
  if (!Number.isFinite(expiresAt) || expiresAt < now) return false;
  const expected = sign(expiresAt);
  if (signature.length !== expected.length) return false;
  return crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected));
}

function requireAdmin(req, res, next) {
  if (!isAdminEnabled()) {
    return res.status(503).json({ error: "admin disabled: ตั้งค่า ADMIN_PASSWORD ใน .env ก่อน" });
  }
  const header = req.get("authorization") || "";
  const token = header.startsWith("Bearer ") ? header.slice(7) : "";
  if (!verifyToken(token)) {
    return res.status(401).json({ error: "unauthorized" });
  }
  return next();
}

module.exports = { isAdminEnabled, passwordMatches, createToken, verifyToken, requireAdmin, TOKEN_TTL_MS };
```

```js
// API สำหรับหน้า admin: login + อ่าน/เขียน data/*.json + preview ข้อความที่บอทจะตอบ
const express = require("express");
const { requireAdmin, isAdminEnabled, passwordMatches, createToken } = require("../middlewares/adminAuth");
const { validatePromotions, validateServices, validateBranches, validateRegions } = require("../services/validate");

function createAdminRouter({ store, messageTable, loginFailureDelayMs = 1000 }) {
  const router = express.Router();

  router.post("/login", async (req, res) => {
    if (!isAdminEnabled()) {
      return res.status(503).json({ error: "admin disabled: ตั้งค่า ADMIN_PASSWORD ใน .env ก่อน" });
    }
    const password = req.body && req.body.password;
    if (!passwordMatches(password)) {
      await new Promise((resolve) => setTimeout(resolve, loginFailureDelayMs));
      return res.status(401).json({ error: "รหัสผ่านไม่ถูกต้อง" });
    }
    return res.json(createToken());
  });

  router.use(requireAdmin);

  // validator ของแต่ละ resource (บางตัวต้องดูข้อมูลอีกไฟล์ประกอบ)
  const validators = {
    promotions: (value) => validatePromotions(value),
    services: (value) => validateServices(value),
    branches: (value) => validateBranches(value, store.get("regions")),
    regions: (value) => validateRegions(value, store.get("branches")),
  };

  for (const name of Object.keys(validators)) {
    router.get(`/${name}`, (req, res) => res.json(store.get(name)));
    router.put(`/${name}`, (req, res) => {
      const errors = validators[name](req.body);
      if (errors.length) {
        return res.status(400).json({ error: "ข้อมูลไม่ถูกต้อง", errors });
      }
      store.set(name, req.body);
      return res.json(store.get(name));
    });
  }

  router.get("/triggers", (req, res) => res.json([...messageTable.getTable().keys()]));

  router.get("/preview/:trigger", (req, res) => {
    const messages = messageTable.getTable().get(req.params.trigger);
    if (!messages) return res.status(404).json({ error: "ไม่พบ trigger นี้" });
    return res.json(messages);
  });

  return router;
}

module.exports = { createAdminRouter };
```

```js
  try { localStorage.removeItem(TOKEN_KEY); } catch { /* ignore */ }

async function request(method, path, body) {
  const token = getToken();
  const res = await fetch(`/api/admin${path}`, {
    method,
    headers: {
      "Content-Type": "application/json",
      ...(token ? { Authorization: `Bearer ${token}` } : {}),

  });
```

`admin/src/hooks/useResource.js`:
```js
import { useCallback, useEffect, useState } from "react";
import { api } from "../api";

const clone = (v) => JSON.parse(JSON.stringify(v));

// โหลด resource หนึ่งชุด แก้ใน draft บันทึกทั้งชุดด้วย PUT
export function useResource(name) {
  const [saved, setSaved] = useState(null);
  const [draft, setDraft] = useState(null);
  const [errors, setErrors] = useState([]);
  const [status, setStatus] = useState("loading"); // loading | ready | saving | error
  const [message, setMessage] = useState("");

  const load = useCallback(async () => {
    setStatus("loading");
    try {
      const data = await api.get(`/${name}`);
      setSaved(data);
      setDraft(clone(data));
      setStatus("ready");
    } catch (e) {
      setStatus("error");
      setMessage(e.message);
    }
  }, [name]);

  useEffect(() => { load(); }, [load]);

  const dirty = draft !== null && JSON.stringify(draft) !== JSON.stringify(saved);

  useEffect(() => {
    if (!dirty) return undefined;
    const handler = (e) => { e.preventDefault(); e.returnValue = ""; };
    window.addEventListener("beforeunload", handler);
    return () => window.removeEventListener("beforeunload", handler);
  }, [dirty]);

  async function save() {
    setStatus("saving");
    setErrors([]);
    setMessage("");
    try {
      const data = await api.put(`/${name}`, draft);
      setSaved(data);
      setDraft(clone(data));
      setStatus("ready");
      setMessage("บันทึกแล้ว");
    } catch (e) {
      setStatus("ready");
      setErrors(e.errors || []);
      setMessage(e.errors && e.errors.length ? "ข้อมูลไม่ถูกต้อง กรุณาตรวจช่องที่มีข้อผิดพลาด" : e.message);
    }
  }

  function reset() {
    setDraft(clone(saved));
    setErrors([]);
    setMessage("");
  }

  return { draft, setDraft, dirty, save, reset, errors, status, message, reload: load };
}
```

```jsx
import { createContext, useContext, useEffect, useState } from "react";
import { useResource } from "./useResource";
import { api } from "../api";

const BranchesContext = createContext(null);

export function BranchesProvider({ children }) {
  const resource = useResource("branches");
  const [regions, setRegions] = useState([]);
  useEffect(() => { api.get("/regions").then(setRegions).catch(() => setRegions([])); }, []);
  const sections = regions.flatMap((r) => r.sections || []);
  return <BranchesContext.Provider value={{ ...resource, sections }}>{children}</BranchesContext.Provider>;
}

export function useBranches() {
  return useContext(BranchesContext);
}
```

```markdown
## Architecture

- **`index.js`** — Express bootstrap. `rawBodySaver` on `express.json({ limit: "2mb", verify })` keeps the raw body for LINE's signature check. Mounts `/webhook` (LINE), `/api/admin` (admin API), `/admin` (static build of the React admin, only if `admin/dist` exists). `GET /` returns `"ok"`.
- **`data/*.json`** — the single source of truth for all bot content: `promotions.json`, `services.json` (service cards + their price images, keyed by `actionText`), `branches.json` (map/contact + `doctors[]` per branch, `enabled`, `menu`, `region`), `regions.json` (bubbles of the "ตารางแพทย์" menu). Edited via the admin UI; `data/backup/` holds the last 20 versions per file (git-ignored).
- **`services/dataStore.js`** — reads/writes those files (atomic write, backup, cache, `onChange`).
- **`services/messageTable.js`** — `build(data)` produces `Map<trigger, Message[]>` using the Flex builders; `createMessageTable(store)` rebuilds on every save. Fixed triggers: `บริการทั้งหมด`, `โปรโมชั่นล่าสุด`, `ตารางแพทย์`, `ตารางแพทย์สาขาทองหล่อ`; per service: `actionText`; per enabled branch: `trigger` and `"สอบถามตารางแพทย์ สาขา" + trigger` (doctor carousels are split every 12).
- **`services/validate.js`** — validation rules applied on every admin PUT (returns `{path, message}[]`).
- **`routes/chatRoute.js`** — webhook only: optional forwarding to CRM, then `messageTable.getTable().get(text)` → `replyMessage`. No match → no reply.
- **`routes/adminRoute.js` / `middlewares/adminAuth.js`** — `POST /api/admin/login` (`ADMIN_PASSWORD` → 12h HMAC token), `GET/PUT /api/admin/{promotions|services|branches|regions}`, `GET /api/admin/triggers`, `GET /api/admin/preview/:trigger`. Without `ADMIN_PASSWORD` every admin endpoint returns 503.
- **`flexmessage/`** — pure Flex builders; they take data as parameters and contain no content.
- **`admin/`** — Vite + React admin UI (HashRouter, `base: /admin/`). `cd admin && npm run dev` (proxies `/api` to :8080) or `npm run admin:build` from the root to produce `admin/dist`.

## Adding or changing content

Use the admin UI at `/admin` (or edit `data/*.json` by hand and restart). Trigger strings must byte-match what the Rich Menu sends.
```
